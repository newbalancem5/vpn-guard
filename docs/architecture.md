# Архитектура desktop-приложения

## Границы ответственности

`apps/desktop/lib/main.dart` — точка сборки зависимостей. Здесь создаются нативный
адаптер, HTTP-инспектор, контроллер сети и поток уведомлений macOS.
`app/vpn_guard_app.dart` отвечает за тему, локаль и время жизни контроллера экрана.

Каждая функциональность находится в `features/<feature>/`:

| Слой | Ответственность | Примеры |
|---|---|---|
| `domain` | Модели и контракты без Flutter, транспорта и текстов интерфейса | `NetworkInspector`, `NetworkFailure`, `RegionPolicy`, `GuardBackend` |
| `data` | Работа с ОС, HTTPS и MethodChannel | `HttpsNetworkInspector`, `SystemRouteLookup`, `NativeGuardBackend` |
| `application` | Состояние, отмена, поколения запросов и жизненный цикл | `NetworkController`, `DashboardController` |
| `presentation` | Экраны и отображение локализованного состояния | Dashboard, Overview, Diagnostics |

Внедрение зависимостей через конструкторы позволяет проверять экран без интернета и
подписанного фильтра. Контроллеры не импортируют конкретные HTTP/нативные реализации.
Ошибки передаются типизированными кодами; перевод выбирается в UI.

## Компоненты и переводы

- `shared/widgets/section_card.dart` — общая карточка с обычным/предупреждающим фоном.
- `shared/widgets/metric_tile.dart` — подпись и выделяемое значение.
- Карточки защиты, сети и приложений принадлежат dashboard; один компонент семейства
  адресов отображает IPv4 и IPv6, один компонент сервиса — ChatGPT и Claude.
- Все авторские тексты Flutter UI, ошибки, названия стран и параметризованные сообщения
  находятся в `lib/l10n/app_en.arb` и `app_ru.arb`. Технические JSON-ключи, имена API,
  идентификаторы каналов и значения ОС остаются стабильными и не переводятся.
- `flutter gen-l10n` создаёт игнорируемый Git каталог `lib/l10n/generated/`.
  `country_names.dart` сопоставляет ISO-коды с сообщениями ARB.
- Для нового сообщения добавьте одинаковый ключ и описание placeholders в оба ARB,
  запустите генератор и обратитесь к `context.l10n`. Для новой локали добавьте ARB и
  пункт выбора языка. Выбор сейчас хранится только на время запуска приложения.
- Названия стран перенесены из локальных данных Foundation/CLDR через
  `tools/export_country_names.swift`; приложение не зависит от macOS для переводов.
- Flutter 3.50 генерирует делегаты старых Material/Cupertino-библиотек. Приложение
  явно использует делегаты `material_ui` и `cupertino_ui`; иначе возникает
  `No MaterialLocalizations found`. Сгенерированные файлы исключены из анализа;
  авторский код проверяется полностью.
- Нативные меню macOS: `apps/desktop/macos/Runner/{en,ru}.lproj/MainMenu.strings`;
  они следуют языку приложения в настройках macOS, отдельно от переключателя Flutter.
- macOS Lab использует `NSLocalizedString` и `macos/Host/{ru,en}.lproj`. Язык выбирает
  ОС. Тексты разрешения расширения находятся в `InfoPlist.strings`.

## Проверка сети

Инспектор делает HTTPS-запросы с принудительным выбором семейства адресов. TLS
проверяет исходное имя сервера; перенаправления запрещены, ответ ограничен 16 КБ.
Геолокация обязана вернуть тот же IP; IPv6 сравнивается в нормализованном виде.
Локальный HTTP/SOCKS-прокси не используется: этот этап предназначен для системного VPN.

Отмена закрывает HTTP-клиенты и сокеты. Каждый запуск получает номер поколения:
ответ предыдущего запроса не может восстановить сброшенное состояние. Есть таймауты
DNS, соединения, HTTP и всей проверки. Обновление сбрасывает прежнее наблюдение;
данные старше 75 секунд не считаются актуальными.

Чтение маршрута выполняется для числового адреса HTTPS-сервера (`route -n get` на
macOS, `Find-NetRoute` на Windows) до и после запроса. Ошибка или ограничения
песочницы дают неизвестный интерфейс. Никакие маршруты не изменяются.

## Политика стран и дальнейшее подключение защиты

`RegionPolicy` хранит датированные независимые снимки официальных списков сервисов.
Обновляйте списки, дату проверки и срок действия после сверки источников, затем
запускайте тесты. Для Claude учитываются явно перечисленные зависимости и территории.
Неизвестная страна, региональное исключение или истёкший снимок не подтверждают допуск.

`AdmissionAssessment` — предварительная оценка условий. `mayAuthorizeTraffic` всегда
`false`: отсутствуют проверенный системный механизм и привязка потока приложения
к VPN. Даже успешный IP-запрос этого не меняет. Flutter не является доверенным
источником разрешений для будущего сервиса.

Следующий этап — аутентифицированный IPC к системным службам macOS/Windows,
проверка идентичности приложения и отзыв разрешений при смене сети. Разрешение будет
действовать только после подтверждения enforcement; текущий MethodChannel не принимает
произвольный ответ `ALLOWED` за доказательство защиты.

IPv6 имеет отдельное условие допуска. Для будущей системной защиты выбран режим:
непроверенный IPv6 блокируется у защищаемых приложений даже при успешном IPv4.
VPN только с IPv4 не требует отключать IPv6 для всей ОС. Это требование к будущему
фильтру, а не описание уже работающей блокировки.
