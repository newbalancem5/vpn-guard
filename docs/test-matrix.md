# Критерии перехода от прототипа к MVP

Успешная сборка, unit-тесты и отсутствие echo не доказывают отсутствие утечек.
Нужно наблюдение на физическом интерфейсе, VPN-интерфейсе и контролируемом endpoint.
Перед каждым негативным сценарием подтверждается работоспособный baseline.

На каждом стенде зафиксировать ОС/архитектуру, Amnezia/протокол/режим полного
туннеля, адреса endpoint, IPv4/IPv6, состояние KillSwitch, версии приложений,
подписи helpers и версию VPN Guard. Текущая матрица ещё не выполнялась.

| Сценарий | Критерий | macOS | Windows |
|---|---|---|---|
| Запуск без VPN | Ни одного прямого пакета защищаемого приложения | NOT RUN | NOT RUN |
| VPN, но IP ещё не проверен | Доступ закрыт | NOT RUN | NOT RUN |
| Подтверждённый допуск | Данные только через выбранный туннель | NOT RUN | NOT RUN |
| Ручное отключение Amnezia | Нет прямого выхода новых и существующих потоков | NOT RUN | NOT RUN |
| Аварийный обрыв, KillSwitch on/off | Тот же критерий независимо от KillSwitch | NOT RUN | NOT RUN |
| Wi-Fi → Ethernet, смена маршрута | Старый допуск аннулирован | NOT RUN | NOT RUN |
| Сон → пробуждение | Доступ закрыт до новой проверки | NOT RUN | NOT RUN |
| Физический IPv6, VPN только IPv4 | Непроверенный IPv6 заблокирован | NOT RUN | NOT RUN |
| TCP, UDP, QUIC | Одинаковый запрет прямого выхода | NOT RUN | NOT RUN |
| DNS от системного резолвера | Проверенный DNS-путь без прямой утечки | NOT RUN | NOT RUN |
| Закрытие Flutter / падение службы | Системный запрет сохраняется | NOT RUN | NOT RUN |
| Падение/перезапуск фильтра | Нет окна прямого выхода | NOT RUN | NOT RUN |
| Перезагрузка ОС | Правила действуют раньше защищаемых приложений | NOT RUN | NOT RUN |
| Обновление приложения/helpers | Покрытие сохраняется либо допуск закрыт | NOT RUN | NOT RUN |
| Проверочный endpoint недоступен | Доступ закрыт, причина доступна в UI | NOT RUN | NOT RUN |
| Удаление | Удалены только собственные правила | NOT RUN | NOT RUN |

Изменение маршрута должно отзывать допуск через события системы. Изменение
внешнего IP на стороне VPN-сервера может быть незаметно локально: для него отдельно
задаются частота проверки и максимальный срок действия допуска. Нельзя обещать
мгновенное обнаружение при периодическом IP-check.

Проверка страны не гарантирует доступность сервиса или отсутствие блокировки аккаунта.
