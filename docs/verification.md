- В 14:00:22 MSK `nesessionmanager` записал остановку VPN Guard (`Plugin was disabled`),
  удаление его конфигурации и остановку связанных сессий. Через 5 секунд зафиксирован
  `Filter extension exit timer expired`. В исходниках действительно отсутствовал

- После отключения: обычный smoke прошёл с 8 echo для каждого из четырёх сочетаний;
  Apple и Cloudflare ответили HTTP 200 по IPv4 HTTPS. Это короткая проверка

## Исправление Team ID в фильтре — расширение версии 5

- Найдено при обзоре кода: provider вызывал `SecCodeCopySigningInformation` без
  `kSecCSSigningInformation`, поэтому `kSecCodeInfoTeamIdentifier` отсутствовал и
  `ApplicationBlockPolicy.matches` не мог совпасть с Antigravity. Блокировка probe
  не пострадала: она использует только identifier.
- Извлечение подписи вынесено в `SignedProcessIdentity.resolve` (GuardCore). Team ID
  возвращается только после `SecCodeCheckValidity` с Apple-anchored требованием.
- Проверка на запущенных процессах (pid + dynamic code, вне sandbox фильтра): прежний
  способ давал пустой Team ID для AmneziaVPN, AmneziaVPN-service и Claude; новый
  вернул `X7UJ388FXK` и `Q6L2SF6YDW`; для Finder Team ID отсутствует, как и ожидалось.
- `swift test`: PASS, 12 тестов. Unsigned Lab и `flutter build macos --debug`: PASS.
- Не проверено: работа внутри установленного sandboxed provider и блокировка
  реальных потоков Antigravity. Требуется подписанная сборка и ручной тест.
