# VPN Guard Desktop

Общий Flutter-интерфейс macOS/Windows. Системная защита пока не подключена.

```sh
flutter pub get
flutter run -d macos
```

На Windows использовать `flutter run -d windows`.
Проверки: `flutter analyze` и `flutter test`.

Архитектура, ограничения и инструкции — в [README проекта](../../README.md).
